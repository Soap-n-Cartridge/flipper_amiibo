# Amiibo Emulator

This app saves Amiibos you already own, so you can use them again later.

You do not need a downloaded list of Amiibos. You do not need a key file for this.

1. Scan your real Amiibo.
2. Save a copy in Favorites.
3. Press Emulate and hold the Flipper on the game reader. The game sees your Amiibo.

The app cannot include Nintendo's key file. You add that file yourself.

A new ID needs that key file. Without it, New UID and Auto UID cannot change the ID. Emulate still works. It uses the ID from your Amiibo.

Open Help in the app for the other steps.
